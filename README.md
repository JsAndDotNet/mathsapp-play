# Quack Maths · Mystical Maths: web preview

**Play:** https://jsanddotnet.github.io/mathsapp-play/

Two quick-fire maths runner games: tap left or right to run through the gate with the right answer.

This repository only holds the built website. It's published automatically from a private repository on every change, so please don't send pull requests here.

**Feedback is very welcome:** open an [issue](https://github.com/JsAndDotNet/mathsapp-play/issues) with what you liked, what you didn't, any bugs (say which game and which phone or browser), and whether you'd want these as phone apps.
